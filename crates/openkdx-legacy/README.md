# openkdx-legacy

Readers and writers for the files the original KDX programs leave on disk: `Accounts.dat`, `KDXServer.stg`, `KDX.stg`, `.hap` appearance files, sound lists, the news store, history logs, and the file catalog. Shared by the server and the client. No network or UI dependency.

Part of [OpenKDX](../../README.md). Licensed under MIT OR Apache-2.0.
